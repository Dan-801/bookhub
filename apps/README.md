# apps/

As aplicações do STAYVILE. Cada uma roda sozinha e tem o próprio README explicando como.

| Pasta | Para que serve |
|---|---|
| [web/](web/) | Frontend: a página onde o usuário busca jogos, empresta e devolve |
| [api/](api/) | Backend: regras de negócio, banco local e integração com o RAWG |

Front e back ficam no mesmo repositório (monorepo), o que reduz a troca de contexto para quem trabalha sozinha.
