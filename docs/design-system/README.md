# design-system/

Documentação da identidade visual e dos componentes da interface.

## O que guardar aqui

- `tokens.md`: os valores visuais definidos uma única vez, como cores, tipografia, espaçamentos, raios de borda e breakpoints. Mudar um token muda todos os componentes que o usam.
- Lista de componentes:
  - **Primitivos**: peças básicas, como Button e Input.
  - **Compostos**: combinações de primitivos, como um formulário de empréstimo.

Em projeto pequeno, prints com uma breve descrição já resolvem. Storybook é opcional.
