# runbooks/

Passo a passo para resolver problemas conhecidos.

## O que guardar aqui

Um arquivo por problema, com:

- **Sintoma**: o que aparece quando dá errado.
- **Causa provável**.
- **Como resolver**: os passos, na ordem.

Exemplos para o STAYVILE: a busca no RAWG não retorna nada (chave da API inválida ou limite de requisições), o banco local não sobe.

Nomeie os arquivos pelo problema, em kebab-case: `rawg-sem-resposta.md`.
