# STAYVILE

- **Trilha:** inicial
- **Acervo:** jogos

## Descrição

A STAYVILE é uma biblioteca digital de jogos em formato de marketplace.
Qualquer usuário busca um jogo pelo nome no RAWG e anuncia a ficha no banco local.
O dono escolhe se oferece o jogo para alugar (valor mensal, por 30 dias), para vender (valor maior, vitalício) ou as duas coisas.
A página registra aluguel, devolução e compra, e mostra os atrasados.

## MVP

Anunciar um jogo, alugar, devolver e comprar pela página, com o status do aluguel sempre visível.
