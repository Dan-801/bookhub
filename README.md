# STAYVILE
-**Trilha:** inicial
-**Acervo:** jogos
## Descição
A STAYVILE é uma biblioteca digital de jogos.
O usuário busca um jogo pelo nome no RAWG e guarda a ficha no banco local.
Cada jogo tem quantiddade disponível e valor de aluguel.
A pagina registra empréstimo, devolução e mostra os atrasados.

##MVP
Buscar um jogo, guardar a ficha, emprestar e devolver pela página, com o status do empréstimo sempre visível.
